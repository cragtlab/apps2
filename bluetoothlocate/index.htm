findphone — one-page Bluetooth finder

Lists Bluetooth devices your browser is already allowed to access, listens for advertisement updates when supported, and shows an estimated distance from signal strength. This is a browser approximation, not a true ranging tool.

How it behaves

Nearest first. Items sort by the strongest recent signal.

Distance is estimated. The page uses a simple path-loss model from RSSI and an assumed transmit reference, so the number is only good for comparing devices in the same room.

Live updates. When the browser supports advertisement watching, the signal bar and distance refresh automatically.

If a device disappears, it is kept in the list until you clear it, so you can see which targets were seen recently.
